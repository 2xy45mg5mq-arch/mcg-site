Intentionally Skipped

These pages were evaluated but left unchanged. Each has a design-specific reason for its current styling.

meatspace.html

Intentionally uses monospace Courier New font, filled white CTA button, and unique separator system. Changing these would break its distinct retro-digital aesthetic.

artci / altindamarlari / losingreality

Already using the winning kanvatan pattern for all 6 element types. These are the standard-setters — no changes needed.

hr-slideshow.html

Full-screen slideshow with no traditional sections, labels, or CTA buttons. No elements to standardize.

tfgame.html

Interactive game with unique UI. Not a portfolio page — excluded from cohesion scope.

index.html CTAs

Homepage .text-link buttons have border-radius: 4px and tinted background. Different purpose (portfolio navigation) than page-level CTAs. Changing would break the homepage card layout.

hr-deep.html section labels

Uses .section-label as oversized display headings (2.9–4.5rem). This is an intentional editorial design, not an inconsistency.

Verdict

14 CSS-only changes across 6 pages. The biggest visual impact is on topfloor.html, where section labels grow from 0.7rem breadcrumbs to 1.4rem headings (matching 5 other pages). All other changes are subtle alignment tweaks — button sizing, text opacity, variable consistency. No content, layout, or accent color changes. Fully reversible via git checkout main -- .
